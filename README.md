# 草坪突击队 · FIELD/OPS

为 iPad 横屏触控制作的第一人称合作游戏。带上原创「红色分节激光枪」，与本地 AI 队友阿光一起清除草坪上的 10 名敌人。

## 启动

```sh
npm install
npm run dev -- --host 0.0.0.0
```

电脑打开终端显示的本地地址（通常是 http://localhost:3000）。在 iPad 上使用 Safari 打开本项目的私有发布链接，并使用拥有该网站的账号登录。

同一 Wi-Fi 下也可在 iPad 打开 `http://电脑的局域网IP:3000`；电脑需要保持运行，并允许本地服务通过系统防火墙。iPad 上的 `localhost` 指 iPad 自己，不能用于连接电脑。

## 操作

| 操作               | iPad             | 电脑                       |
| ------------------ | ---------------- | -------------------------- |
| 移动               | 左下摇杆         | WASD / 方向键              |
| 瞄准               | 拖动右侧空白区域 | 鼠标；不支持锁定时按住拖动 |
| 攻击               | 按住右下开火按钮 | 按住鼠标左键               |
| 跳跃               | 跳跃按钮         | 空格                       |
| 精确瞄准           | 瞄准按钮         | 右键 / E                   |
| 换武器             | 点击底部武器     | 1–6 / Q                    |
| AI 跟随 / 留守掩护 | 点击指挥按钮     | C                          |
| 暂停               | 右上暂停按钮     | Esc / P                    |

点击「出发，队友！」后会随机出现在一栋楼顶。坡道连接草坪与屋顶，也可以直接跳下，没有坠落伤害。清除全部敌人获胜；玩家生命归零则可重新开始。离开窗口会自动暂停。

## 已实现

- 五栋带坡道建筑、大草坪和每局随机分布的九块石头；敌人和玩家的碰撞体与身高相同。
- 分节激光枪、手枪、狙击枪、武士刀、匕首和金箍棒。激光显示为分离的红色光段；队友激光为青色，方便辨认。
- 远程弹道、建筑及石头遮挡、有限距离近战、友军免伤、辅助瞄准、无限弹药。
- 阿光沿地图寻路跟随，或留在原位掩护，自动攻击可见敌人；倒下后 12 秒原地修复。敌人会追踪小队并使用各自武器。
- 生命值、敌人数、小地图、音效开关、暂停、胜负结算、重开；短暂脱战后生命恢复。
- 所有游戏资源随构建提供；不依赖外部模型、图片或字体。AI 是本地行为逻辑，无需 AI 服务费用或 API 密钥。

## 项目结构

- `game/rules.ts`：地图、地形碰撞、A* 寻路、射线、武器和伤害规则。
- `game/simulation.ts`：可独立测试的固定时间步长战斗模拟。
- `game/scene.ts`：Three.js 场景、机器人和武器模型。
- `game/engine.ts`：渲染循环、粒子、HUD、小地图及游戏生命周期。
- `game/input.ts` / `game/audio.ts`：多指触控、键鼠和按用户手势启动的音频。
- `app/page.tsx` / `app/globals.css`：中文菜单、HUD、触屏控制和响应式布局。

## 验证

```sh
npm test
npm run typecheck
npm run lint:game
npm run build
```

核心测试覆盖随机出生、地形可达性、碰撞遮挡、近战范围、友军保护、投射物命中、AI 跟随与留守、暂停、跳跃和胜负。`npm run lint` 还检查生成的完整组件目录；其中未修改的通用组件存在上游 lint 报错，游戏代码可独立使用 `lint:game` 检查。

本版本尚未进行实际 iPad 设备测试，触屏手感、帧率及具体 iPadOS 兼容性仍需真机体验确认。Three.js 需要 WebGL 2。使用 HTTPS 发布地址时可用 Safari「添加到主屏幕」进入；离线缓存尚未实现。

页面包含可选 WebMCP `get_game_state`、`start_new_game`、`command_teammate` 工具，并在不支持的浏览器中自动跳过。当前未在支持 WebMCP 的浏览器上下文中验证其注册和调用，不作为已验证功能交付。

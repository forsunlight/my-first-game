# 草坪突击队

用户已确认于当前空目录实现 iPad 横屏网页第一人称合作战斗游戏。

- 玩家从五栋建筑中随机一栋楼顶出发，AI 队友在旁边出生。坡道连接地面与屋顶，可跳下，不造成坠落伤害。
- 大草坪、少量随机石头，敌人与玩家近似等大；敌人携带武士刀、匕首、狙击枪、手枪、金箍棒。
- 玩家默认使用原创红色分节激光枪，可切换全部六种武器。远程攻击被地形挡住；近战有距离限制。
- AI 队友沿可行走地形跟随或留在指定位置掩护，自动瞄准和射击。AI 为本地游戏行为，不依赖服务、账号或大模型 API。
- 触屏使用左摇杆移动、右侧拖动瞄准、按住射击、跳跃、切武器和指挥队友。电脑支持 WASD、鼠标、空格、Q、C、Esc。
- 10 名敌人，清除后胜利；玩家生命耗尽后失败；两种结果均可重新开始。暂停及离开窗口时停止游戏。
- 明亮的低多边形建筑和机器人角色，击中闪光、击败消散，无血腥。中文游戏原生开始界面、生命值、敌人数、准星、小地图和触屏按钮。
- React UI / Three.js rendering / independent deterministic world, collision, navigation and combat functions. Keep all resources local to the build; no external runtime asset dependency.
- 验证随机出生、坡道通行、碰撞、寻路、攻击遮挡、近战范围、友军保护与胜负；完成 TypeScript 检查和生产构建。实际 iPad 兼容性需设备验证，不把桌面检查称为真机测试。

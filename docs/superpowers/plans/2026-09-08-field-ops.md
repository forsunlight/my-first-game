# Field Ops Implementation Plan

**Goal:** 在当前目录交付可以在 iPad Safari 上玩的第一人称 AI 合作游戏。

**Architecture:** React renders menus and HUD while a Three.js engine owns the animation loop. Pure TypeScript owns world generation, terrain, pathfinding, ray collision, weapons and match rules, so gameplay correctness is testable without WebGL.

**Tech Stack:** Generated Sites/Vinext, React, Three.js, TypeScript, Node test runner.

## Tasks

- [ ] 1. Establish gameplay regression tests in `tests/rules.test.ts`. Run `node --experimental-strip-types --test tests/rules.test.ts` and confirm missing gameplay behavior fails. Implement `game/rules.ts`: seeded worlds, five roofs and ramps, random collision-free spawns, step-safe movement, ground/roof navigation, ray/sphere and ray/box intersections, weapon rules, team protection and match outcome. Run the tests again.
- [ ] 2. Build first recognizable slice: `game/scene.ts` creates sunny low-poly arena, roof identifiers and robots; `app/page.tsx` and `app/globals.css` render a Chinese start screen over live 3D scenery. Update `app/layout.tsx` metadata. Compile, request dev route and open the first preview.
- [ ] 3. Implement `game/engine.ts`, `game/input.ts`, `game/audio.ts`: fixed-step actors, AI paths and cover orders, visible segmented red projectiles, ray-obstructed combat, weapon view models, sound after user interaction, pause and cleanup. Connect the HUD and touch controls in `app/page.tsx`. Keep game state out of React's per-frame render loop.
- [ ] 4. Verify through seeded automated simulations and `npx tsc --noEmit`, `npm run build`. Fix any failures with a regression test when meaningful. Document local startup and iPad access in `README.md`. Use hosting skill to deliver a reachable link if available; retain local project as requested.

## Validation examples

```sh
node --experimental-strip-types --test tests/rules.test.ts
npx tsc --noEmit
npm run build
```

Expected: pass roof-spawn coverage, same-size actors, unobstructed randomized ground spawns, paths that reach each rooftop by a ramp, wall-blocked projectiles, bounded melee, no friendly fire and terminal results; typecheck exits 0 and production build succeeds.
